# 去 / 删 / 改 前后对照示例（before-after.md）

示例为演示三类优化的通用形态，非真实仓库内容。

## 原始片段（Before）

~~~~markdown
<!-- README.md -->
# MyTool

MyTool 是一个非常强大、灵活、易于使用的工具。

## 安装

安装非常简单，只需轻松运行下面的命令，即可快速上手：

~~~bash
pip install mytool==1.2.3
~~~

## 快速开始

（同上段安装步骤，又贴了一遍完全相同的命令）

~~~bash
pip install mytool==1.2.3
~~~

## 未来规划

我们将在近期（大概 2022 年左右）上线插件系统，敬请期待。

## 配置

使用 --output-dir 指定输出目录，默认输出到 ./out。

详见 [官网](https://example.com/pricing)。
~~~~

## 优化后（After）

~~~~markdown
# MyTool

## 安装

~~~bash
pip install mytool
~~~

## 配置

使用 --out-dir 指定输出目录，默认输出到 ./build。

详见[官方文档](https://docs.mytool.example)。
~~~~

## 改动对照与证据

| 类别 | 严重度 | 原内容 | 动作 | 证据 |
|---|---|---|---|---|
| A 去冗余 | Low | 首句「非常强大、灵活、易于使用」口水词堆砌 | 删除 | 无信息量，属目标 A 信号词 |
| A 去冗余 | Medium | 「非常简单，只需轻松」「即可快速上手」套话 | 删除 | 冗余修饰 |
| A 去冗余 | Medium | 「快速开始」复制了安装命令 | 删除整节 | 同一命令第二处，与「安装」重复 |
| C 纠事实 | High | 固定版本 pin 1.2.3，而当前发布已更新 | 去掉版本号 | 对照安装源与 CHANGELOG |
| B 删失效 | High | 「近期(大概 2022)上线插件系统」早已过期 | 删除整节 | 当前日期远超 2022，且无此功能 |
| C 纠事实 | High | --output-dir / 默认 ./out 与当前代码不符 | 改为 --out-dir / ./build | grep 代码默认值，diff 显示参数已改名 |
| C 纠事实 | Medium | 链接文本「官网」实为定价页，且域名已换 | 改为官方文档链接 | 请求旧链接跳转/失效；新域名为当前真实入口 |

## 要点

- 只动了「冗余 / 失效 / 错误」三处，没有重写语气、没有新增章节、没有重排。
- 每处都有证据列；证据不足的改动不会出现在 After 里（会标 NEEDS_HUMAN）。
